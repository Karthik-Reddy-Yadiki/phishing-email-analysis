# Phishing Analysis Report 03 – "Aquaspins" Fake Casino Bonus Lure

## Summary
An English-language online casino lure ("Aquaspins") promising "100% up to $750 + 200 free spins + 1 Bonus Crab". It was sent from **the same throwaway Microsoft 365 tenant as Report 01**, through Google's Gmail API, and every link points to **the same malicious domain as Report 01** (`woondsplay[.]com`). The email personalises the sender display name with the victim's address and imitates a legitimate gambling newsletter, including a responsible-gambling disclaimer.

## Analysis

**Header analysis.** Same pattern as Reports 01 and 02: a Microsoft 365 From address, but the message was created through the Gmail API and sent from a Google server, so SPF fails, and DKIM only passes for Google's own unaligned signing domain. The tenant `gbnfrostbornwarriors02` is identical to Report 01; only the mailbox name changed (`sage.jones` → `alex.martinez`), showing the attacker rotates fake personas within one account.

**Personalisation.** The display name inserts the victim's own email address ("your bonus <victim>"), so the message looks addressed specifically to them. The subject uses gift emojis to catch attention in the inbox.

**Content analysis.** The email imitates a professional casino newsletter: a logo, a "Welcome Pack" offer (100% up to $750 + 200 free spins), feature icons and a **responsible-gambling disclaimer**. The disclaimer is a credibility trick – it copies wording found in legitimate gambling marketing to lower the reader's guard. Invisible zero-width characters after the preview text and hidden random text (`display:none`, ×3) are used to evade spam filters.

**Link analysis.** All five links point to `woondsplay[.]com` and use exactly the same URL structure as Report 01 (`search=`, `d378x5`, `xxx-205`, `lm=164627...`, `sd=5`, `page=`). The values are near-identical but not the same: this email uses `d37825`, `869-205` and `lm=164627...1595127`, while Report 01 uses `d37875`, `907-205` and `lm=164627...1595116`. This suggests sequential campaign or batch IDs generated by the same mailing tool, with a unique four-letter code and `page=` value per link for click tracking.

**Threat intelligence.**
- **VirusTotal:** `woondsplay[.]com` – 7/92 vendors flagged it (see Report 01): alphaMountain.ai (Phishing), Rising (Malicious), ESET (Suspicious), Forcepoint ThreatSeeker (Spam).
- **urlscan.io:** DNS resolution error – the domain no longer resolves (see Report 01).

## Verdict
**Malicious – Fake casino bonus scam with phishing intent**, part of the same campaign as Reports 01 and 02. Likely aims to collect personal and payment details through a fraudulent "deposit bonus" sign-up.

## Recommended Actions
- Block `woondsplay[.]com` at the email gateway and web proxy; check `imgprom[.]com` reputation and block if malicious.
- Block the entire `gbnfrostbornwarriors02[.]onmicrosoft[.]com` tenant, not just individual mailboxes, since the attacker rotates mailbox names.
- Hunt for all messages from `*.onmicrosoft.com` senders that fail SPF and originate from the Gmail API, and remove them.
- Check proxy logs for visits to `woondsplay[.]com`; follow up with users who clicked (card/password reset if details were entered).
- Report the abusive tenant to Microsoft.
- Do **not** block `74.125.224.41` – it is shared Google mail infrastructure.
